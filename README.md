# anjaliml.github.io

Minimal personal website for Anjali Suman.

Live at [anjaliml.github.io](https://anjaliml.github.io/).

The [CV page](https://anjaliml.github.io/cv/) loads the current PDF from the `main` branch of
[Anjali_CV](https://github.com/AnjaliML/Anjali_CV) when opened. The viewer uses
[PDF.js](https://mozilla.github.io/pdf.js/) under the Apache 2.0 license.
